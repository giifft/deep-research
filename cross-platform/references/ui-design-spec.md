# 核心 UI 设计规范与系统能力集成 (Integrated UI Design Specification)

> [!IMPORTANT]
> **单一事实来源 (Single Source of Truth)**：本文件已完整集成原 `UI_DESIGN_SPEC.md` 与 `UI_DESIGN_SPEC_yth.md` 中的所有 UI 设计规范。项目在执行任何 UI 界面设计、Marp 渲染、VBA 宏编写或 PptxGenJS 页面生成时，必须以本规范为**最高优先级指南**。

## 1. 颜色系统与设计令牌 (Color System & Design Tokens)

项目支持以**绿色主题（品牌绿，默认）**为主、**蓝色主题**为备选的主题体系。所有色彩必须严格遵循以下色值设定（在 PptxGenJS 代码中一律去掉 `#` 前缀）：

### 绿色主题（品牌绿，默认首推）
- **主色系**：
  - 主品牌绿 (`--main-color` / `theme.secondary`)：`#07978D` —— 用于按钮、选中激活、高亮图标、强调文字。
  - 深主色绿 (`--main-dark-color` / `theme.primary`)：`#027C76` —— 用于标题、深色背景、渐变终止色、按钮按下态。
  - 浅主色绿 (`--main-light-color`)：`#14aaa1` —— 用于悬停（hover）态。
  - 翠绿高亮 (`--line-color2` / `theme.accent`)：`#0FB886` —— 用于正向指标、特殊高亮点缀。
- **背景色**：
  - 页面大底色 (`--bg-color` / `theme.bg`)：`#F6FBFC`
  - 卡片/内容区底色 (`--bg-color3` / `#FFFFFF`)：`#FFFFFF` (或 `#eFF2F6` 轻量底)
  - 高亮区域底色 (`--bg-color4` / `theme.light`)：`#ebf7fa`
  - 表格表头/二级容器底色 (`--bg-color2`)：`#F1F6F7`
- **文字色**：
  - 一级标题/主文字 (`--text-color`)：`#162B41`
  - 正文/表格文字 (`--text-color1`)：`#262626`
  - 次要正文 (`--text-color2`)：`#333333`
  - 提示/次要文字 (`--text-color3`)：`#7B8EA2`
  - 章节标题/深主题色 (`--text-color4`)：`#00706B`
- **边框色**：
  - 输入框/搜索边框色 (`--border-color`)：`#A3D4D1`
  - 通用分割线 (`--border-line`)：`#E8E8E8`

### 蓝色主题（备选）
- 蓝色主色：`#036DC7`
- 蓝色深色：`#1875F0`
- 蓝色轻量高亮背景：`#E9F3FB`
- 蓝色边框色：`#95BFE5`

### 语义色彩规范
- **成功状态**：`#52C41A` (成功绿，用于正向数据指标)
- **警告状态**：`#FA8C16` (警告橙)
- **错误状态**：`#FF4D4F` (错误红，用于负向/下降指标)
- **信息提示**：`#1890FF` (信息蓝)

## 2. 文本与数据格式规范 (Text & Data Formats)

任何数据在输出到界面、卡片或表格时，必须经过如下规则过滤与自动转换：
1. **千分位**：所有数值和金额必须携带千分位分割符（如 `1,234,567.00`）。
2. **单位自动换算**：
   - 整数位数 $\ge 5$ 位：自动除以 10000 换算为 **万**。
   - 整数位数 $\ge 9$ 位：自动除以 100000000 换算为 **亿**。
3. **小数位数**：百分比、金额和比率类数据，四舍五入并强制保留**两位小数**。
4. **数字格式示例**：
   - 数值：`1,000人` / `1.00万人` / `1,000.00万人` / `1.00亿人`
   - 金额：`1,000.00元` / `1.50万元` / `2.06亿元`
5. **排版省略规则**：普通文本溢出时使用 `...` 折行或隐藏，但**数字及金额类数据绝不可隐藏或省略**。

## 3. 字体与字号层级规范 (Typography)

### 字体族建议
```css
font-family: system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
```
*在 PPT 及 VBA 生成中，中文统一使用 `"Microsoft YaHei"` (微软雅黑)，英文使用 `Arial` 或 `Calibri`。*

### 字号与字重层级
- **超大标题 / 核心指标数值**：`24px` / `28pt` ~ `36pt` | 加粗 (Bold 700)
- **模块标题 / 看板卡片标题**：`20px` / `20pt` ~ `22pt` | 加粗 (Bold 700)
- **页面主标题 / 区块标题**：`18px` / `16pt` ~ `18pt` | 常规/加粗 (Regular 400 / Medium 500)
- **次级标题 / 菜单项**：`16px` / `14pt` | 常规/中等 (Medium 500)
- **正文 / 表格内容**：`14px` / `11pt` ~ `12pt` | **常规 (Regular 400，严禁加粗)**
- **辅助说明 / 树节点**：`13px` / `10pt` | **常规 (Regular 400，严禁加粗)**
- **注释 / 图例 / 数据来源**：`12px` / `9pt` ~ `10pt` | **常规 (Regular 400，严禁加粗)**

*等宽数字：对所有数值使用 `font-variant-numeric: tabular-nums;` 确保列对齐。*

## 4. 栅格、间距与圆角规范 (Grids & Layouts)

### 栅格系统 (Grid)
- 采用 **24 栅格** 设计。
- 页面安全边距：左右 **32px** (或 0.5")，内容区上下边距 **24px** (或 0.4")。
- 卡片间距 / 水槽 (Gutter)：固定 **24px** (或 0.35")，卡片与卡片之间横向及纵向的间距需保持一致。
- 模块控制：单屏核心模块数量控制在 **5 ~ 9 个**，避免信息过载。

### 间距步进 (Spacing)
采用 4px/8px 步进系统：
- 极小间距 (`space-xs`)：**4px**
- 紧凑/组件内距 (`space-sm`)：**8px**
- 标准间距 (`space-md`)：**12px**
- 卡片内边距 (`space-base`)：**16px** (或 `padding: 10px 15px` 的标准容器)
- 区块间距 (`space-lg`)：**24px**
- 页面大边距 (`space-xl`)：**32px**

### 圆角与阴影
- **圆角 (Border Radius)**：
  - 按钮、输入框、常规卡片：**4px** (或 PptxGenJS 中的 `rectRadius: 0.05` ~ `0.1`)
  - 弹窗容器：**8px**
  - 标签 / 徽章 / 页码：**12px** (或 `rectRadius: 0.15` ~ `0.2` 的 pill 风格)
  - 头像 / 圆形图标背景：**50%**
- **阴影 (Shadow)**：
  - `shadow-sm` (轻微浮起)：`0 1px 2px rgba(0,0,0,0.03)` (用于轻量筛选条)
  - `shadow-md` (标准卡片)：`0 2px 8px rgba(0,0,0,0.08)` (用于区块容器，offset: 2, blur: 6)
  - `shadow-lg` (弹窗浮起)：`0 4px 16px rgba(0,0,0,0.12)`

## 5. 核心组件开发规范 (Component Specifications)

### 5.1 指标条与指标卡 (Metric Cards)
- **指标卡宽度**：同一指标条上的指标卡宽度必须相同，宽度**不得小于 144px**。
- **单行指标数量**：单行指标建议在 **2 ~ 6 个**。超过 6 个时，必须切换为**不带图标的纯文字单指标**，且提供左右滚动切换按钮。
- **指标卡混搭**：
  - 横向指标卡（单行 2-4 项）与竖向指标卡（单行 5-6 项）不可在同一条指标条内混搭。
  - 内嵌迷你图表等自定义指标卡，可以与常规横向/竖向指标卡其一进行混搭。
- **ICON 图标**：图标为装饰性非必选，单行有 6 个及以上指标卡时**绝对禁止**添加 ICON 图标。

### 5.2 按钮组件 (Buttons)
- **主按钮**：绿色背景（`#07978D`） + 白色文字。
- **次按钮**：白色背景 + 绿色边框（`#07978D`）。
- **文字按钮**：无背景色 + 绿色文字（`#07978D`）。
- **弹窗按钮规范**：底部有多个操作按钮时，**必须且仅允许包含一个绿色焦点按钮**，且该焦点按钮必须位于**最右侧**。

### 5.3 弹窗组件 (Modals)
标准弹窗设计尺寸：
- **大弹窗**：`1000px × 610px`
- **中弹窗**：`800px × 500px`
- **小弹窗**：`400px × 250px`

### 5.4 表格组件 (Tables)
- **表头**：浅灰色背景（`#FAFAFA`），文字加粗。
- **数据行**：白色背景，行与行之间采用细线分割，交替背景色使用 `#F1F6F7`。
- **分页控制**：默认每页显示 **20 条** 数据，页码导航在底部右侧呈列。

### 5.5 图标组件 (Icons)
- **尺寸**：标准尺寸为 `24×24px`，大尺寸为 `32×32px`。
- **风格**：统一使用描边宽度为 `2px` 的线性图标（Outlined），圆角收端。
- **状态颜色**：默认状态使用灰色描边（`#7B8EA2`），选中/激活状态使用白色描边+绿色背景填充。
