# 天机妙策局

> 12 位三国谋士组成的**自进化** AI 深度研究团队。懂政治、懂经济、懂站位，通过闭环复盘与动态专家配置不断自我完善。

---

## 这是什么

一个能在 ChatGPT / Claude / DeepSeek / Cursor / CodeBuddy / WorkBuddy / Trae Solo 等 18 个 AI 工具中使用的央企深度研究系统。

12 个角色各司其职，按 **6 阶段自进化流水线**协作，产出带多源引用的研究报告、项目方案、专利交底书和学术论文。

## 核心能力：自进化 (Self-Evolution)

本系统不仅是一个静态的 Prompt 集合，更引入了自进化闭环：
1. **动态专家进化 (Phase 2.5)**：针对垂直前沿课题，团队自动进化出第 13 位特邀专家参与研究。
2. **复盘与进化日志 (Phase 6)**：每次交付后，主编诸葛亮带领团队总结审稿驳回点和用户反馈，生成“进化规约”并写入 `evolution_log.md`，用于下一次研究的防御性增强。

## 快速开始

**最快 1 分钟上手**：打开 `cross-platform/orchestrator.md`，全选复制，粘贴到任何 AI 对话窗口，发送你的研究需求。


```
帮我深度调研中国能源央企数字化转型的现状、挑战与路径
```
